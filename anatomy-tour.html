A SMALL NETWORK YOU CAN ACTUALLY TRAIN
Does the error reach the encoder?


Yes. Cross-attention reads the encoder's features through its keys and values. Changing those features changes the prediction—and therefore the loss.


This miniature makes that dependency executable: 8 synthetic RGB frames → 16 tubelets → one local and one global self-attention layer → one cross-attention layer → a scalar point-coordinate prediction. It has  trainable scalars. The two query targets come from a known moving point.


A deliberately small teaching network, not a D4RT reproduction. It uses two encoder residual connections and fixed teaching position features; it omits normalization, MLPs, multi-head attention, camera coordinates and auxiliary heads. Its query uses target time and a one-pixel RGB appearance sample instead of the paper’s full query and 9 × 9 crop. It fits two queries from one clip; lower training loss demonstrates gradient flow, not generalization.

V: [8,4,4,3] → tubelets: [16,24]
X = tubelets @ Wpatch + fixed_position        # [16,4]
L = X + local_attention(X)                    # [16,4]
F = L + global_attention(L)                   # [16,4]
Q = [target_time, 1, source_RGB] @ Wquery      # [2,4]
R = softmax(Q @ (F @ Wkey)ᵀ / 2) @ (F @ Wvalue)
prediction = R @ Whead + bias                  # [2,1]
loss = mean((prediction − target)²)
loss.backward()                               # reverse-mode autodiff
θ ← θ − 0.06 · clipped_gradient               # teaching SGD
Tubelets contain 2 × 2 × 2 RGB pixels, scaled to [0,1]. Query vectors encode target time, a constant and a one-pixel RGB sample from the source frame. The targets are the normalized x coordinate of a synthetic translating point at two times. The network reads no target coordinates as input. Weight initialization is deterministic. D4RT uses its own larger architecture, geometric objectives and AdamW recipe.

THE ACTUAL TRAINING RUN
Where the supervision comes from.
1 · Labeled video
Sample source points from known trajectories; transform their target positions into the requested camera frame.
2 · Predictions
Encode the clip and decode sampled queries. Labels stay outside the forward inputs.
3 · Available losses
Compare 3D geometry and auxiliary predictions only where each label exists.
4 · Joint update
Backpropagate through heads, decoder, query embeddings and encoder. Recompute features after updating weights.
The reported run uses 48-frame 256² clips, 2,048 queries, 500k AdamW steps and 64 TPU chips. VideoMAE initialization and D4RT geometry training are separate stages. §4 ↗ Initialization ablation ↗

YOUR GENIE COMPARISON
Same attention vocabulary.
Different information paths.
QuestionD4RTOriginal Genie · 2024
What is a token?A continuous feature from a video tubelet.The video tokenizer produces discrete VQ codes.
How does evidence move?Local frame-wise and full-clip global attention.Spatial attention, then causal temporal attention at the same spatial address.
What does the model answer?Geometry for a queried point, time and camera.Next-frame video tokens conditioned on past tokens and latent actions.
Tubelet grouping and temporal attention are separate operations: the first gathers pixels; the second exchanges information between already embedded tokens. A tubelet stays at an image address even when an object moves. In Genie, spatial and temporal layers compose to pass information across both dimensions.
“ST-transformer” is the original Genie paper's term. The D4RT temporal patch size does not establish that it uses Genie's causal ST block. Genie §2 / Figure 3 ↗ D4RT §2.2 ↗
