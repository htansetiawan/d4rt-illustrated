THE TENSOR SHAPES HAVE A COMPUTE COST
Longer video and more questions cost different things.






G = temporal groups, S = spatial tokens per group, M = queries. Doubling clip length doubles local attention entries and quadruples global entries. Doubling queries doubles decoder entries while leaving the encoder unchanged. These are logical score counts per head and layer, not FLOPs, allocated memory or measured latency.

01 / PIXELS → VECTORS
What is actually inside a token?

  
Two 16 × 16 patches, at the same image address in adjacent frames. That is 1,536 RGB values—not an object, a word, or a codebook entry.

SHARED LEARNED PROJECTION
z = x W + b
Six illustrative output channels, computed from this tubelet using fixed teaching weights. D4RT learns its projection; C stays symbolic here. Position encoding is added before contextual attention.

    
24 time groups × 16 rows × 16 columns = 6,144 tokens

  

  
A fixed address, not a track.
The object can leave the patch between frames. Tokenization groups nearby pixels; the encoder must learn how evidence at different addresses relates across time.
Fewer tokens is not a VQ codebook.
The projection maps pixel volumes to continuous vectors. D4RT’s described encoder does not round these vectors to discrete code IDs. The local 9 × 9 query crop is a separate path into the decoder.

This executable block is a standard pre-norm transformer teaching implementation, with deterministic features and weights. It exposes calculations, not trained D4RT activations. D4RT’s head count, feature width, normalization variant and MLP expansion are not inferred from this miniature.

  
Self-attention in the encoder.
Q, K and V are all projected from the video feature stream. Context is written back to video tokens. The MLP then transforms each token’s channels; residual connections preserve a route for its previous representation.
Cross-attention in the decoder.
Q comes from the point query. K and V come from F. Queries read the scene without reading one another: an M × N relation, not M × M query self-attention. More queries increase decoding work without requiring the clip to be encoded again.

THE ACTUAL TRAINING RUN
Where the supervision comes from.
1 · Labeled video
Sample source points from known trajectories; transform their target positions into the requested camera frame.
2 · Predictions
Encode the clip and decode sampled queries. Labels stay outside the forward inputs.
3 · Available losses
Compare 3D geometry and auxiliary predictions only where each label exists.
4 · Joint update
Backpropagate through heads, decoder, query embeddings and encoder. Recompute features after updating weights.
The reported run uses 48-frame 256² clips, 2,048 queries, 500k AdamW steps and 64 TPU chips. VideoMAE initialization and D4RT geometry training are separate stages. §4 ↗ Initialization ablation ↗
INITIALIZATION
Learn video features.
VideoMAE pretraining learns to reconstruct masked video. The D4RT appendix studies using those encoder weights as initialization.

D4RT TRAINING
Learn geometry.
The encoder and decoder train end-to-end on available point-level geometric targets. The sampled labels supervise a shared representation.

INFERENCE
Reuse the scene.
Weights are fixed. Encode the observed clip once; vary the point and three times to ask for depth, tracks or point clouds.

Where to ask.
Each training clip contributes 2,048 sampled queries. A 30% branch targets boundaries; a 40% branch forces target and camera times to agree. The rest can agree by chance too. Sparse decoding saves output work while gradients still train the shared encoder.
What the data must provide.
The mixture includes synthetic and real sources: Kubric, PointOdyssey, Dynamic Replica, ScanNet and other public and internal datasets. Each supplies the labels it has. Unlabeled RGB alone does not supply this complete geometry objective.


Read the optimization recipe and what remains unspecified
AdamW; 500,000 steps; local batch 1 across 64 TPU chips. Weight decay 0.03. Warm up for 2,500 steps to 10⁻⁴, then cosine decay to 10⁻⁶. Clip gradient L2 norm at 10. Reported training time: just over two days on that hardware.
Video augmentation is temporally consistent and includes color changes, blur, crops and temporal-stride sampling. Coordinates and geometry labels must follow the image transformations. The complete internal-data mixture, encoder layer schedule and implementation details are not reconstructed by this companion.

A SMALL NETWORK YOU CAN ACTUALLY TRAIN
Does the error reach the encoder?


Yes. Cross-attention reads the encoder's features through its keys and values. Changing those features changes the prediction—and therefore the loss.


This miniature makes that dependency executable: 8 synthetic RGB frames → 16 tubelets → one local and one global self-attention layer → one cross-attention layer → a scalar point-coordinate prediction. It has  trainable scalars. The two query targets come from a known moving point.


A deliberately small teaching network, not a D4RT reproduction. It uses two encoder residual connections and fixed teaching position features; it omits normalization, MLPs, multi-head attention, camera coordinates and auxiliary heads. Its query uses target time and a one-pixel RGB appearance sample instead of the paper’s full query and 9 × 9 crop. It fits two queries from one clip; lower training loss demonstrates gradient flow, not generalization.

Inspect the miniature's math and exact scope
V: [8,4,4,3] → tubelets: [16,24]
X = tubelets @ Wpatch + fixed_position        # [16,4]
L = X + local_attention(X)                    # [16,4]
F = L + global_attention(L)                   # [16,4]
Q = [target_time, 1, source_RGB] @ Wquery      # [2,4]
R = softmax(Q @ (F @ Wkey)ᵀ / 2) @ (F @ Wvalue)
prediction = R @ Whead + bias                  # [2,1]
loss = mean((prediction − target)²)
loss.backward()                               # reverse-mode autodiff
θ ← θ − 0.06 · clipped_gradient               # teaching SGD
Tubelets contain 2 × 2 × 2 RGB pixels, scaled to [0,1]. Query vectors encode target time, a constant and a one-pixel RGB sample from the source frame. The targets are the normalized x coordinate of a synthetic translating point at two times. The network reads no target coordinates as input. Weight initialization is deterministic. D4RT uses its own larger architecture, geometric objectives and AdamW recipe.

YOUR GENIE COMPARISON
Same attention vocabulary.
Different information paths.
D4RT / RECONSTRUCT AN OBSERVED CLIP
Tubelet projection→Local ↔ global attention→Continuous F
Point queries read F through cross-attention. No discrete-code lookup is described in this path.
GENIE / ORIGINAL ST-TRANSFORMER BLOCK
Spatial attention→Causal temporal attention→Feed-forward
A temporal sublayer reads one spatial address across time. The preceding spatial sublayer lets that address carry evidence from other locations. Genie's video tokenizer uses ST blocks and vector quantization.
QuestionD4RTOriginal Genie · 2024
What is a token?A continuous feature from a video tubelet.The video tokenizer produces discrete VQ codes.
How does evidence move?Local frame-wise and full-clip global attention.Spatial attention, then causal temporal attention at the same spatial address.
What does the model answer?Geometry for a queried point, time and camera.Next-frame video tokens conditioned on past tokens and latent actions.
Tubelet grouping and temporal attention are separate operations: the first gathers pixels; the second exchanges information between already embedded tokens. A tubelet stays at an image address even when an object moves. In Genie, spatial and temporal layers compose to pass information across both dimensions.
“ST-transformer” is the original Genie paper's term. The D4RT temporal patch size does not establish that it uses Genie's causal ST block. Genie §2 / Figure 3 ↗ D4RT §2.2 ↗
