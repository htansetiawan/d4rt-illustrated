Does “independent queries” mean the model ignores the rest of the video?

No. Each query can read the shared scene representation. Independence is between decoder queries, not between the input video frames. Think of several readers consulting the same notebook.

06 / CHECK YOUR INTUITION

What changed: the world or the ruler?

A statue is stationary. You keep its source point and target time fixed, but select a different camera frame. Must its output coordinates stay the same?

Choose an answer to reveal the explanation.

A useful distinction

Reconstruction describes what is in a scene. Tracking links the same physical point across time. A sequence of unrelated 3D snapshots does not automatically supply those links.

Read predictions as predictions

A location inferred behind an obstacle is not a new camera observation. This distinction matters whenever an application acts on uncertain geometry.
